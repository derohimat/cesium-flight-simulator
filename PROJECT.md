# Project: Aleph 3D Capture Importer & Custom Scenery Environment

## Architecture
The Aleph 3D Capture Importer enables users to import real-world textured photogrammetric 3D models (`mesh.glb`) generated by Aleph into the Sky Studio cinematography suite of Cesium Flight Simulator. The architecture spans client-side storage, Cesium 3D scene rendering, cinematography trajectory generation, and React UI controls:

1. **Ingestion & Storage Layer** (`packages/web/src/services/`):
   - `alephParser.ts`: In-browser binary GLB reader (via `DataView`) extracting `asset.extras` (latitude, longitude, base elevation, radius, bounds) without third-party dependencies, plus JSON/ZIP metadata extractors.
   - `sceneryStorage.ts`: IndexedDB database (`AlephSceneryDB`, v1) with dual object stores:
     - `captures`: Lightweight JSON metadata index for instant UI listing.
     - `models`: Binary Blobs / ArrayBuffers of GLBs, accessed on-demand via transient Object URLs (`URL.createObjectURL(blob)`).
   - Bundled Sample: `packages/web/public/samples/colosseum/` containing valid `mesh.glb` with embedded `asset.extras`, `metadata.json`, and thumbnail.

2. **Cesium 3D Scenery & Isolation Layer** (`packages/web/src/cesium/managers/`):
   - `CustomSceneryManager.ts`: Lifecycle manager for custom glTF/GLB models.
     - Loads model via `Cesium.Model.fromGltfAsync` with `allowPicking: false` to avoid GPU readback stalls in `GroundSampler`.
     - In-place mutation of `primitive.modelMatrix` via `Cesium.Transforms.headingPitchRollToFixedFrame` for real-time altitude, heading, and scaling adjustments.
     - Scenery Isolation: Controls clipping planes (`ClippingPlaneCollection`) or tileset visibility on `Scene.ts`'s `GooglePhotorealistic3DTileset` to eliminate z-fighting and visual collision with background geometry.

3. **Cinematography & Timeline Layer** (`packages/web/src/services/cinematography/`):
   - `CinematographyPresets.ts`: Parametric camera path generators:
     - **360° Orbit**: Circular ENU trajectory at radius $R \times 1.8$ and elevation $H$, looking at center.
     - **Cinematic Fly-by**: Tangential approach and departure spline path past the model.
     - **Spiral Reveal**: Ascending helical trajectory starting low and close, expanding outward.
   - Emits standard `Keyframe[]` consumed by `FlightTimeline.tsx`.

4. **UI Layer** (`packages/web/src/react/`):
   - `LocationLibrary.tsx`:
     - Drag-and-drop dropzone + file input for GLB / JSON / packages.
     - Category filter tab for `'custom'` ("My Locations", 📍).
     - Model Inspector drawer for selected custom locations: real-time sliders (altitude offset -100m..+100m, heading 0..360°, scale 0.1..5.0x) and scenery isolation toggle.
     - Cinematography preset buttons ("360° Orbit", "Fly-by", "Spiral Reveal").
   - `StudioModeUI.tsx`:
     - Mounts `FlightTimeline.tsx` as a bottom dock with playback, scrubbing, and keyframe manipulation.

## Code Layout
- `packages/web/src/services/aleph/`:
  - `alephParser.ts`: Binary GLB parser & metadata extractor
  - `sceneryStorage.ts`: IndexedDB storage engine
  - `types.ts`: TypeScript interfaces for Aleph captures
- `packages/web/src/cesium/managers/`:
  - `CustomSceneryManager.ts`: Cesium GLB lifecycle, transform matrix updates, clipping planes
- `packages/web/src/services/cinematography/`:
  - `CinematographyPresets.ts`: Mathematical camera moves (Orbit, Fly-by, Spiral)
- `packages/web/src/react/features/studio/components/`:
  - `LocationLibrary.tsx`: Updated with dropzone, custom tab, inspector sliders, preset triggers
  - `FlightTimeline.tsx`: Connected to timeline state & preset generation
- `packages/web/src/react/layouts/`:
  - `StudioModeUI.tsx`: Bottom dock mounting for FlightTimeline
- `packages/web/public/samples/colosseum/`:
  - `mesh.glb`, `metadata.json`, `thumbnail.jpg`
- `tests/e2e/`:
  - Opaque-box automated test suites for Aleph import, persistence, Cesium placement, and cinematography

## Interface Contracts

### AlephCaptureMetadata
```typescript
export interface AlephCaptureMetadata {
  id: string;
  name: string;
  lat: number;
  lon: number;
  baseAltitude: number;
  altitudeOffset: number;
  heading: number;
  scale: number;
  radius: number;
  bounds?: [number, number, number, number]; // [minLat, minLon, maxLat, maxLon]
  thumbnailUrl?: string;
  importedAt: number;
  isBundled?: boolean;
  isolationEnabled: boolean;
}
```

### Ingestion & Storage (`alephParser.ts` & `sceneryStorage.ts`)
```typescript
export interface ISceneryStorage {
  init(): Promise<void>;
  saveCapture(metadata: AlephCaptureMetadata, glbBlob: Blob): Promise<string>;
  getAllCaptures(): Promise<AlephCaptureMetadata[]>;
  getCaptureMetadata(id: string): Promise<AlephCaptureMetadata | null>;
  getModelBlob(id: string): Promise<Blob | null>;
  getModelUrl(id: string): Promise<string | null>;
  updateMetadata(id: string, updates: Partial<AlephCaptureMetadata>): Promise<void>;
  deleteCapture(id: string): Promise<void>;
}
```

### Custom Scenery Management (`CustomSceneryManager.ts`)
```typescript
export interface ICustomSceneryManager {
  loadScenery(capture: AlephCaptureMetadata, modelBlobUrl: string): Promise<void>;
  updateTransform(altitudeOffset: number, heading: number, scale: number): void;
  setIsolation(enabled: boolean): void;
  unloadScenery(): void;
  getActiveBoundingSphere(): { center: Cesium.Cartesian3; radius: number } | null;
}
```

### Cinematography Presets (`CinematographyPresets.ts`)
```typescript
export interface PresetOptions {
  centerLat: number;
  centerLon: number;
  baseAltitude: number;
  radius: number;
  durationSeconds?: number;
}

export interface ICinematographyPresets {
  generateOrbitKeyframes(options: PresetOptions): Keyframe[];
  generateFlyByKeyframes(options: PresetOptions): Keyframe[];
  generateSpiralRevealKeyframes(options: PresetOptions): Keyframe[];
}
```
